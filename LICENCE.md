## 🧩 About

**MapleStory External Menu** is a curated list of MapleStory open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap viewer, coordinate tracker
- **Quality-of-Life Helpers** — inventory catalog, skill manager, overlay notes
- **Research Notes** — training layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Minimap Overlay — always-visible map with player marker
- Coordinate Tracker — display current position on screen
- Skill Cooldown Notes — visualize cooldown timers
- Movement Speed — adjust movement for study (0.5x to 2x)

### Wallhack
- Item Catalog — browse equipment, consumables, etc.
- Custom Outfit Notes — organize cosmetic sets
- Damage Skin Preview — preview visual effects

### Aimbot
- Training Map Notes — segment study on any map
- Platform Highlight — see platform edges
- Jump Height Notes — chain complex maneuvers in practice
